ホームページ 更新マニュアル

Salon Ciel. Chiba ／ 週1回の更新を想定した、いちばん簡単な手順

目次
  1. 管理画面に入る
  2. お知らせを書く(いちばんよく使います)
  3. ブログを書く
  4. 写真の入れ方・トップ写真の差し替え
  5. 料金を変える
  6. よくある質問を足す・直す
  7. 電話・営業時間・住所・予約URLを変える
  8. 臨時休業・営業時間変更を知らせる
  9. 公開前チェック(最初の1回だけ)
  10. 日々の保守(月1回の確認)
  11. 困ったとき

1. 管理画面に入る

  1. ブラウザで https://(サイトのアドレス)/wp-admin を開きます。
    ※実際のアドレスは、公開時にここへ書き込んでください。
  2. ユーザー名とパスワードを入れて、ログインします。
  3. 左側に黒いメニューが出ます。以降の手順は、このメニューから始めます。
パスワードは他の人に教えない・紙やメモに残さない。パスワード管理アプリの利用がおすすめです。

2. お知らせを書く

トップページの「お知らせ」欄に、新しい順で表示されます。

  1. 左メニューの 投稿 → 新規投稿を追加 をクリック。
  2. いちばん上に タイトル を入れます(例:11月の営業日のお知らせ)。
  3. 本文を入力します。改行は Enter、写真は本文の「＋」ボタンから入れられます。
  4. 右側の「カテゴリー」で 「お知らせ」にチェック を入れます。
    ※チェックを忘れると、トップのお知らせ欄に出ません。
  5. 右上の 公開 を押し、もう一度出る 公開 を押します。
  6. トップページを開いて、お知らせ欄に出ていることを確認します。
日付を指定して予約投稿したいときは、「公開」の横の「すぐに」をクリックして日時を選び、「予約」を押します。

お知らせを直す・消す

  1. 投稿 → 投稿一覧 で対象の記事にマウスを合わせ、「編集」を押します。
  2. 直したら右上の 更新 を押します。
  3. 消すときは、一覧で「ゴミ箱へ移動」を押します。(ゴミ箱の中は、あとで戻せます)

3. ブログを書く

手順は、お知らせと同じです。違うのはカテゴリーだけです。

  1. 投稿 → 新規投稿を追加 を開きます。
  2. タイトルと本文を入れ、「お知らせ」のチェックは入れません(必要なら別のカテゴリーを選びます)。
  3. 見出しをつけると読みやすくなります。本文の「＋」→「見出し」を選びます。
  4. 右上の 公開 を押します。
ブログは、メニューの「ブログ」ページに一覧で出ます。お知らせにも出したい場合は、「お知らせ」にもチェックを入れてください。

4. 写真の入れ方・トップ写真の差し替え

記事に写真を入れる

  1. 本文の「＋」を押して 画像 を選びます。
  2. 「アップロード」でパソコンやスマホの写真を選びます。
  3. アップロード後、右側の「代替テキスト」に写真の説明を一言入れます(例:店内の様子)。
お客様の顔が写っている写真は、必ず本人の了承を得てから載せてください。写真は横幅1,500px程度・2MB以内がおすすめです(大きすぎると表示が遅くなります)。

トップページの写真を差し替える

  1. 左メニューの 外観 → カスタマイズ を開きます。
  2. サロン情報(Salon Ciel) → 写真の差し替え を選びます。
  3. 差し替えたい場所(メイン写真・特徴①〜③・代表・アクセス)の「画像を選択」から写真を選びます。
  4. 右側のプレビューで確認し、上の 公開 を押します。
写真を設定しなかった場所には、最初から入っている写真が表示されます。元に戻したいときは「削除」を押してください。

5. 料金を変える

  1. 左メニューの 料金メニュー を開くと、料金の一覧が出ます。
  2. 変えたい行の「編集」を押します。
  3. 「料金の設定」の枠で、時間・料金・説明 を直します。(料金は「6,000円」のように、円まで書きます)
  4. 右上の 更新 を押します。

メニューを増やす・減らす・並べ替える

  • 増やす: 料金メニュー → 新規追加。タイトルに名前(例:全身本格整体)を入れ、「料金の設定」を入力して「公開」。
  • 減らす: 一覧で「ゴミ箱へ移動」。
  • 並べ替え: 編集画面の右側「ページ属性」にある「順序」に数字を入れます。小さい数字ほど上に出ます。
  • 新規お試しの枠: 目立つ枠に表示されるのは、「目立たせる」にチェックの入ったメニューです。
トップの大きな「新規お試し 4,980円」の数字は、ここではなく 外観 → カスタマイズ → 基本情報・営業時間 の「新規お試し料金」で変えます。両方を合わせてください。

6. よくある質問を足す・直す

  1. 左メニューの よくある質問 を開きます。
  2. 直すときは、対象の「編集」を押します。タイトルが質問、本文が答え です。
  3. 足すときは 新規追加 を押し、質問と答えを入れて「公開」します。
  4. 並び順は、料金メニューと同じく「順序」の数字で変えます。

7. 電話・営業時間・住所・予約URLを変える

  1. 外観 → カスタマイズ → サロン情報(Salon Ciel) を開きます。
  2. 変える内容に応じて、次の項目を開きます。
  3. 直したら、上の 公開 を押します。
基本情報・営業時間電話番号、営業時間(平日・土日祝)、郵便番号、住所、アクセス案内、新規お試しの料金と説明
リンク予約ページのURL、LINEのURL、問い合わせページのURL
写真の差し替えトップ・特徴・代表・アクセスの写真
公開設定検索エンジンに表示するかどうか
ここを直すと、トップページ・全ページ下部の予約バー・フッターなど、サイト全体の表示がまとめて変わります。

8. 臨時休業・営業時間変更を知らせる

よくある更新です。次の2つを組み合わせます。

  1. 「お知らせ」を書く(手順2)。例:「12/30〜1/3は年末年始休業です」
  2. 通常の営業時間そのものが変わるときは、手順7で営業時間を直します。
  3. 休業が終わったら、お知らせはそのまま残して構いません(古い日付で履歴になります)。

9. 公開前チェック(最初の1回だけ)

新しいサイトを本番のアドレスで公開するときに行います。

  1. 外観 → カスタマイズ → サロン情報 → 公開設定 を開きます。
  2. 「検索エンジンに表示しない」の チェックを外し 、「公開」を押します。
    ※公開前は、Googleに表示されないよう、チェックが入っています。
  3. 左メニューの 設定 → 表示設定 で、「検索エンジンでの表示」のチェックも外れていることを確認します。
  4. 投稿一覧から、サンプル記事「新しいホームページを公開しました(サンプル記事)」を削除するか、内容を書き換えます。
  5. トップから全ページを開いて、電話・予約・LINEのボタンが動くか確認します。

10. 日々の保守(月1回の確認)

  1. 管理画面にログインし、左メニュー ダッシュボード → 更新 を開きます。
  2. WordPress本体・プラグイン・テーマの更新があれば、「更新」を押します。(自動更新を入れている場合は不要です)
  3. サーバーのバックアップが取られているか、サーバー管理画面(Xserver のサーバーパネル)で確認します。
  4. サイトを開いて、表示が崩れていないか確認します。
更新の前には、必ずバックアップがあることを確認してください。更新後に表示がおかしくなったら、何もせず、このマニュアルの「困ったとき」に進んでください。

11. 困ったとき

ログインできないログイン画面の「パスワードをお忘れですか?」から、登録メールアドレスで再設定します。
お知らせがトップに出ない投稿のカテゴリーに「お知らせ」が入っているか、「公開」になっているか(下書きのままではないか)を確認します。
変えたのに反映されないブラウザの再読み込み(Ctrl+F5 / スマホは履歴を消して再表示)を試します。カスタマイズは、上の「公開」を押し忘れていないか確認します。
表示が崩れた・真っ白になった直前に行った操作を覚えておき、作業を止めて、制作担当に連絡してください。
間違えて消した投稿・料金・質問は「ゴミ箱」にあります。各一覧の上にある「ゴミ箱」から「復元」できます。
次のことは、しないでください:プラグインやテーマの勝手な追加・削除、「外観 → テーマ」の変更、「ツール」や「設定」の変更(手順9を除く)。
