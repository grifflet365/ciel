# Salon Ciel Renewal (WordPress テーマ)

## 入れ方
1. このフォルダ `salon-ciel-renewal` を ZIP にする
2. WordPress 管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロード
3. 有効化すると、固定ページ(部位別5・施術メニュー・ホーム・ブログ)、料金6件、FAQ8件、お知らせのサンプルが自動作成されます

## 更新のしかた
- お知らせ / ブログ: 「投稿」(お知らせはカテゴリ「お知らせ」)
- 料金: 「料金メニュー」 / 質問: 「よくある質問」
- 電話・営業時間・住所・LINE・予約URL・写真: 外観 → カスタマイズ → 「サロン情報(Salon Ciel)」
- 公開時: 「公開設定」の「検索エンジンに表示しない」をオフにする
